## 2. 总体架构

**单前端 bundle，多 Tauri 窗口**：窗口 label 决定角色 — `manager`（主管理器）/ `note-<uuid>`（每张便签一个真实原生窗口）。

```
src/                          # React/TS：只做 UI 与交互
├── app/                      # 入口、按 window-label 路由、主题
├── features/
│   ├── notes/                # 便签列表、便签窗口外壳、生命周期
│   ├── editor/               # Markdown 编辑器（唯一渲染模块，不散落）
│   ├── todo/                 # checkbox 解析/勾选回写
│   ├── reminders/            # 提醒设置 UI、snooze
│   ├── shortcuts/            # 快捷键注册/冲突/恢复默认
│   ├── settings/             # 设置页（主题/开机/关闭行为/导出导入）
│   ├── search/               # 全局搜索
│   └── archive/              # 归档/恢复/永久删除
├── components/               # shadcn/ui 生成件 + 通用组件
├── stores/                   # zustand（UI 状态）
├── hooks/ ─ lib/ ─ types/

src-tauri/src/                # Rust：只做系统能力
├── db/                       # rusqlite 连接池(Mutex<Connection>) + migrations/ + DAO
├── commands/                 # 全部 #[tauri::command]（薄层，委托模块）
├── notes/                    # 便签业务 + 归档生命周期 + 图片清理
├── window/                   # 多窗口创建、几何持久化(去抖)、显示器越界校正、置顶、全屏跟随(WinEventHook 事件驱动)
├── vdesktop/                 # Windows 虚拟桌面：IVirtualDesktopPinnedApps COM PinWindow；失败→显式 unsupported，不伪造
├── tray/                     # 托盘菜单
├── reminder/                 # tokio sleep_until 事件驱动调度器（无轮询），启动时补发过期
├── shortcut/                 # 全局快捷键注册/冲突检测/重载
├── filesystem/               # images/ 目录管理、备份、错误日志(error/*.md)
└── lib.rs
```

**数据目录**：`%APPDATA%/Focusly/` → `database.sqlite (WAL)`、`images/`、`backups/`、`logs/`。启动时自动轮转备份。

## 3. 数据库（rusqlite + PRAGMA user_version 迁移，7 张表）

- `notes(id, title, content, content_format, status[active|archived], is_pinned, is_always_on_top, show_on_all_desktops, desktop_pin_state, fullscreen_behavior[normal|always_top|fullscreen_show|fullscreen_hide], x, y, width, height, monitor_id, created_at, updated_at, archived_at)`
- `note_images(id, note_id→CASCADE, path, filename, width, height, created_at)`
- `reminders(id, note_id→CASCADE, remind_at, repeat_type[once|daily|weekly|weekdays], status[pending|triggered|dismissed|done|cancelled], created_at, triggered_at)`
- `tags(id, name UNIQUE)`、`note_tags(note_id, tag_id)`
- `shortcuts(action PK, accelerator, enabled)` — show_all/hide_all 与 toggle 合一：`toggle_notes`=Ctrl+Shift+Space、`new_note`=Ctrl+Shift+N、`focus_search`=Ctrl+Shift+F
- `settings(key, value)` — theme、close_action、autostart、start_minimized、launch_show_notes

## 4. 关键实现决策

- **自动保存**：编辑 → zustand dirty → debounce 500ms → `update_note`；窗口 `onCloseRequested` 先 flush 再放行关闭；SQLite WAL + synchronous=NORMAL 抗崩溃。
- **窗口几何**：Rust 侧监听 Moved/Resized，800ms 去抖写 DB（含显示器 device name）；恢复时 EnumDisplayMonitors 校验相交，越界则层叠回屏。
- **虚拟桌面**：`IVirtualDesktopPinnedApps::PinWindow`（任务栏右键"在所有桌面显示"同源机制），GUID 取自公开维护的逆向工程常量并运行时特性检测；COM 调用失败 → 状态置 `unsupported`，UI 明确提示"当前系统不支持"，**不伪造成功**。
- **全屏跟随**：`SetWinEventHook(EVENT_SYSTEM_FOREGROUND)` 事件驱动（非轮询）+ 前台窗口矩形==显示器矩形判定全屏 + `DwmGetWindowAttribute(DWMWA_CLOAKED)` 排除已 cloaked 窗口；按每张便签的 fullscreen_behavior 应用 显示/隐藏。
- **提醒**：Rust tokio 任务持有最小到期时间，`sleep_until` 精确等待；CRUD 经 mpsc 唤醒重排；触发 → Windows 通知 + 状态写 DB + 事件给前端；主窗口/便签全部隐藏照常工作；启动时补发 overdue；支持稍后提醒(5m/30m/1h/明天/自定义)。
- **图片**：拖拽/粘贴/选择 → 复制到 `images/<note_id>/<uuid>.<ext>`，`image` crate 读宽高，DB 存元数据；`assetProtocol` 作用域仅 `images/**`；删除便签级联清理文件，归档保留；渲染时检测路径失效显示占位。
- **链接**：统一走 Rust `open_external`，白名单 http/https，其余拒绝。
- **Markdown/Todo**：唯一 `features/editor` 模块：textarea 编辑 + react-markdown/remark-gfm 预览（表格/删除线/代码块/任务列表），预览中 checkbox 点击回写源文本对应行；`- [ ] / - [x]` 即待办的结构化真相，搜索统计直接扫 content。
- **托盘/关闭**：托盘：显示全部/隐藏全部/新建便签/打开管理器/设置/退出；主窗口关闭默认最小化到托盘（设置可改为退出）；便签窗口关闭=归档进回收站。
- **主题**：浅/深/跟随系统，class 策略，全窗口同步。

## 6. 风险与对策

- **MSVC 安装慢/失败** → 备选 rustup GNU 工具链（Tauri 可用但次选）
- **npm/crates.io 慢** → 耐心等待 + 必要时配置镜像
- **虚拟桌面 COM 在特定 Win11 版本失效** → 已内建 unsupported 显式降级路径
- 范围控制：P2（历史记录/每日统计等）不做，登录/云/Electron 等禁项不碰
